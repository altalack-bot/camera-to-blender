## 🛠️ Troubleshooting

### The tool won't open
Try right-clicking the downloaded file and selecting "Run as administrator." If you get a SmartScreen warning, click "More info" then "Run anyway" – that's normal for new software.

### My camera isn't being detected
Check that your camera works with other apps first (like the Camera app built into Windows). If it works there, restart this tool. If your camera is already in use by another program, close that program and try again.

### The photo appears but looks stretched
In Blender, select the image plane and use the scale tool (press S) to adjust it to your liking. Also check the aspect ratio settings in the tool if available.

### Nothing shows up in Blender
Make sure Blender is running before you capture the photo. Also check that you're in Object Mode in Blender, not Edit Mode.
